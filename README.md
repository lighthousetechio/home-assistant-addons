# CorvidCloud — Home Assistant Add-ons

Official Home Assistant add-ons for [CorvidCloud](https://github.com/lighthousetechio), an IP video surveillance platform with remote access, recording, and license plate recognition.

## Installation

In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**, then add:

```
https://github.com/lighthousetechio/home-assistant-addons
```

The add-ons listed below will appear in the store once the repository is loaded.

> Requires Home Assistant **OS** or **Supervised** — `Container` and `Core` installations have no Supervisor and cannot run add-ons.

## Add-ons

- [**CorvidCloud**](cloudgateway/) — Bridges RTSP/ONVIF cameras on your LAN to the CorvidCloud video surveillance platform.
