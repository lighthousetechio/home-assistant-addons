# Corvid Cloud — Home Assistant Add-ons

Official Home Assistant add-ons for Corvid Cloud, an IP video surveillance platform with remote access, recording, and license plate recognition.

## Installation

> **Not via HACS.** This is a native Supervisor add-on — install it from the built-in Add-on Store, not from HACS.

In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**, then add:

```
https://github.com/lighthousetechio/home-assistant-addons
```

The add-ons listed below will appear in the store once the repository is loaded.

> Requires Home Assistant **OS** or **Supervised** — `Container` and `Core` installations have no Supervisor and cannot run add-ons.

## Add-ons

- [**Corvid Cloud Gateway**](cloudgateway/) — Bridges RTSP/ONVIF cameras on your LAN to the Corvid Cloud video surveillance platform.
